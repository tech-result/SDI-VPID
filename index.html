Notes

This helper follows the practical VPID table structure used by common waveform monitors: UDW1 = payload identifier, UDW2 = transport/picture/transfer/rate, UDW3 = aspect/colorimetry/horizontal/sampling, UDW4 = link/audio/color-format/bit-depth. Some fields are standard-dependent; reserved bits are kept at zero. S-Log3 is not a fixed ST 352 transfer characteristic; use Unspecified / camera log and document it externally if needed.
